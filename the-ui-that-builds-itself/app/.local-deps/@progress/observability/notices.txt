  humanfs: A modern filesystem API for JavaScript by Nicholas C. Zakas

  If you find this useful, please consider supporting my work with a donation
  or nominate me for a GitHub Star.

  Description This is the monorepo for humanfs, a modern filesystem API for
  JavaScript. Most of the filesystem APIs provided by JavaScript runtimes were
  designed to emulate Linux utilities which, while making them easy to adopt
  and understand, often requires writing way more code than necessary for
  common tasks. humanfs is a new approach that streamlines the most common
  operations while providing useful ways to test the expected functionality.
